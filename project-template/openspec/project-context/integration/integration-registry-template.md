# 集成注册表模板

## 使用规则

本模板用于沉淀长期稳定的集成事实。接入项目时可按实际情况拆分为：

- `dubbo-api-registry.md`
- `mq-topic-registry.md`
- `job-registry.md`
- `external-system-registry.md`
- `runtime-config-registry.md`

不要把单次需求临时细节写入注册表；只有被真实代码、配置或人工确认的长期事实才进入本文件。
