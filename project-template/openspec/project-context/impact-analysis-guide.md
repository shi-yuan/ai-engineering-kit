# 影响分析指南

## 目的

本文用于指导大型历史复杂业务系统的跨模块、跨仓库、跨异步链路影响分析。执行任何非全新功能变更前，应先依据本指南完成 `00-change-analysis.md`。

## 通用搜索边界

所有搜索以 `.agent-env.md` 中 `WORKSPACE_ROOT` 为边界。不要只分析当前 OpenSpec 目录，也不要只分析单个 Maven/Gradle/npm 模块。

优先识别：

- API/SDK 契约层。
- HTTP Controller、RPC Provider、MQ Consumer、Job、Listener 等入口。
- 核心 Service、Domain、Manager、Adapter。
- DAO、Mapper、Repository、Model。
- 配置、缓存、锁、枚举、状态机。
- 管理端、报表、导出、对账、补偿任务。
- 外部系统 Client、渠道适配器、回调处理器。

## 按变更类型分析

### 接口能力变更

必须检查：

- HTTP/RPC/API 入口和全部调用方。
- DTO、枚举、错误码、默认值、空值语义。
- 兼容旧客户端、灰度期间新旧版本共存。
- 超时、重试、限流、熔断、鉴权。
- 入口日志、审计、追踪字段。

必须确认：

- 新字段是否可选。
- 老调用方不传字段时的行为。
- 返回结构或错误码变化是否影响上游重试和异常处理。

### 状态机变更

必须检查：

- 状态枚举、状态流转方法、更新 SQL、CAS 条件。
- Job、MQ、回调、补偿是否会重复推进状态。
- 管理端是否允许人工修正状态。
- 报表、对账、下游通知是否依赖状态。

必须确认：

- 哪些状态是终态。
- 哪些状态允许回退或重试。
- 历史数据中的旧状态、空状态、异常状态如何处理。

### 数据库变更

必须检查：

- 表、字段、业务键、唯一键、索引。
- 查询条件、更新条件、分页、排序。
- 读写路径和历史数据量级。
- 数据迁移、回滚、默认值、NULL 语义。
- Mapper XML、Model、DTO、导出字段是否一致。

必须确认：

- 生产 DDL 是否与测试或文档一致。
- 新索引是否覆盖核心查询。
- 批量操作是否会放大锁等待或慢 SQL。

### MQ/异步链路变更

必须检查：

- Topic、Tag、Producer、Consumer、Group。
- 消息体字段、序列化格式、老消息兼容。
- 重复消费、乱序、延迟、重试、死信。
- 事务提交与消息发送顺序。
- 消费失败后的补偿路径。

必须确认：

- 是否存在多个 Consumer Group。
- 是否有 Workspace 外消费者。
- 是否允许同一业务键重复消息。

### Job/补偿变更

必须检查：

- Job 名称、cron、分片、开关、运行参数。
- 重复执行、并发执行、补偿窗口。
- 查询条件、分页游标、单批规模。
- 与在线请求、MQ 消费、人工操作的并发关系。

必须确认：

- Job 是否生产启用。
- 历史失败数据如何被重新扫描。
- 回滚后是否会重复补偿。

### 外部系统/渠道变更

必须检查：

- Client/Adapter、签名、加密、验签、超时、重试。
- 外部状态码与内部状态映射。
- 回调、主动查询、对账或补偿。
- 测试环境与生产环境差异。
- 幂等单号、外部流水号、错误码语义。

必须确认：

- 外部接口文档是否与当前接入代码一致。
- 处理中、成功、失败、无记录等状态如何映射。
- 外部重复回调或重复请求的语义。

### 高风险核心业务变更

涉及资金、库存、授信、合同、权限、计费、清结算、履约等核心业务时，必须额外检查：

- 金额/数量/额度/权限边界。
- 主单与明细合计关系。
- 多账户、多租户、多组织隔离。
- 冻结、解冻、占用、释放、冲正、回补等反向动作。
- 对账、报表、审计、财务手工流程。
- 资损、超卖、越权、重复扣减、重复发放等风险。

## 横向影响检查

每次变更至少做一次横向检查：

| 维度 | 搜索对象 | 输出 |
|---|---|---|
| API/RPC | 接口名、Provider 注解、Consumer 注解、DTO、枚举 | Provider/Consumer 清单 |
| MQ | Topic、Tag、Producer、Consumer、Group、发送方法、监听注解 | Producer/Consumer/Group/Tag |
| Job | Job 注解、任务类、调度配置、开关配置 | Job 名称、cron、状态 |
| DB | Mapper XML、Repository、Model、Service 调用 | 表、字段、SQL、索引 |
| Redis/Cache | key、setNx、lock、cache annotation | 幂等锁、缓存、锁粒度 |
| 配置 | 配置 key、默认值、动态刷新注解 | 配置 key、默认值、待确认 |
| 回调/Event | callback、listener、event handler | 回调和事件链路 |
| 管理端/报表 | admin、manage、export、report、reconcile | 查询、导出、对账影响 |

## 输出要求

影响分析必须输出：

- 受影响模块和仓库。
- 受影响入口和调用链。
- 受影响表、字段、业务键和状态。
- 受影响 RPC/MQ/Job/配置/缓存。
- 受影响上下游和外部系统。
- 不能确认的运行态事实。
- 不应纳入本次变更的边界。
- 推荐验证场景和人工确认项。
