# 运行态配置清单模板

## 使用规则

运行态配置包括 Apollo、Nacos、Spring 配置、环境变量、数据库配置表、开关表、定时任务开关、渠道开关等。凡是会影响设计、实现或验证结论的配置，都应在分析中明确证据或标记为待确认。

## 变更检查

新增或修改配置时必须检查：

- Key 是否与已有配置冲突。
- 默认值是否能保护未配置环境。
- 灰度期间新旧配置是否兼容。
- 是否需要动态刷新。
- 是否需要运维、测试、生产分别配置。
- 是否影响 Job、MQ Consumer、RPC Client 或外部系统开关。
