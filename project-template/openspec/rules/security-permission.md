# 安全与权限规则

## 适用范围

修改登录态、鉴权、角色、权限、租户、组织、商户、数据范围、后台操作、导出、脱敏时适用。

## 必须检查

- 调用方身份。
- 权限点和角色。
- 租户、组织、商户、门店、用户等数据隔离维度。
- 后台操作审计。
- 导出和查询是否越权。
- 敏感字段脱敏。
- 老接口或灰度期间权限兼容。

## 禁止事项

- 不得绕过现有鉴权入口。
- 不得扩大查询数据范围而不验证权限。
- 不得在日志、报表、导出中泄露敏感数据。
- 不得把前端隐藏按钮当作权限控制。

## Verification 要求

- 验证有权限用户。
- 验证无权限用户。
- 验证跨租户、跨组织、跨商户访问。
- 验证后台审计记录。
