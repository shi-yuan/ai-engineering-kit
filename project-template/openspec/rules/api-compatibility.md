# API 兼容性规则

## 适用范围

修改 HTTP API、RPC API、SDK、DTO、VO、枚举、错误码、回调协议、导出协议时适用。

## 必须检查

- 全部调用方和被调用方。
- 老字段、老枚举、老错误码是否仍可处理。
- 新字段是否可选，默认值是否安全。
- 返回结构变化是否影响老客户端。
- 灰度期间新旧版本是否共存。
- 文档、SDK、测试用例是否需要同步。

## 禁止事项

- 不得删除公共字段或改变字段含义而不提供兼容方案。
- 不得让老调用方因为新增必填字段失败。
- 不得擅自改变错误码语义。
- 不得把接口调用成功等同于业务处理成功。

## Verification 要求

- 验证老请求。
- 验证新请求。
- 验证字段缺失。
- 验证未知枚举或未知状态。
- 验证错误码和异常路径。
