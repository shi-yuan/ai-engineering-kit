# 事务与一致性规则

## 适用范围

涉及状态变化、核心数值变化、跨库、RPC、MQ、Job、缓存、外部系统调用、补偿、最终一致性时适用。

## 必须检查

- 本地事务边界。
- 外部调用发生在事务内还是事务外。
- MQ 发送时机。
- 状态 CAS 或乐观锁。
- 分布式锁、Redis 锁、数据库唯一键。
- 重复请求、重复消费、重复 Job。
- 失败补偿和最终一致收敛路径。
- 回滚后新旧数据兼容。

## 禁止事项

- 不得把外部调用和本地事务假定为原子操作。
- 不得在无幂等保护时增加重试。
- 不得删除状态保护条件。
- 不得让补偿任务和实时链路互相覆盖终态。
- 不得吞掉异常而没有日志、告警或补偿。

## Design 要求

Design 必须说明：

- 哪些操作在同一事务内。
- 哪些操作是最终一致。
- 幂等键和状态保护。
- 重试、补偿和人工修复路径。
- 异常场景下系统如何收敛。

## Verification 要求

- 重复请求。
- 重复消息。
- 重复 Job。
- 并发更新。
- 外部超时、失败、回调乱序。
- 补偿任务重复执行。
