# 日志与可观测性规则

## 适用范围

修改核心业务链路、外部调用、状态变化、异步消费、Job、补偿、人工操作入口时适用。

## 必须检查

- 是否记录业务主键、外部流水号、请求 ID 或 trace ID。
- 状态变化是否有前后状态。
- 外部调用是否记录请求摘要、响应摘要、错误码和耗时。
- MQ Consumer、Job 是否记录重复执行和失败原因。
- 异常降级或吞异常是否有告警或补偿。
- 敏感信息是否脱敏。

## 禁止事项

- 不得记录密码、Token、密钥、身份证、手机号等敏感明文。
- 不得只打印“失败”而没有业务定位信息。
- 不得吞掉异常且没有任何可观测信号。

## Verification 要求

- 核心场景能通过日志定位业务单。
- 异常场景能通过日志定位失败阶段。
- 高风险链路需要明确告警或人工排查入口。
