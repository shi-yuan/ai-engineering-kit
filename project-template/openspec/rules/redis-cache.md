# Redis / Cache / Lock 规则

## 适用范围

修改 Redis Key、缓存、分布式锁、幂等 Key、限流、短期状态、分布式计数时适用。

## 必须检查

- Key 维度和命名空间。
- 过期时间。
- 新旧 Key 兼容。
- 锁范围、锁粒度、锁超时。
- 异常释放、误释放、续期。
- 缓存读写双方。
- 缓存穿透、击穿、雪崩风险。
- 与数据库事务的边界关系。

## 禁止事项

- 不得改变 Key 维度而不处理老 Key。
- 不得用过短锁超时保护长事务。
- 不得在无 owner 校验时释放锁。
- 不得把缓存值当作唯一事实来源。

## Verification 要求

- 验证重复请求。
- 验证锁冲突和锁释放。
- 验证缓存缺失、过期、脏值。
- 验证配置未开启或 Redis 异常时行为。
