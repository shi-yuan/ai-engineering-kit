## Agent 搜索规则

分析需求时：

1.  先根据业务域确定候选仓库。
2.  搜索入口和核心 Domain Symbol。
3.  遇到跨进程调用，继续搜索 Provider / Consumer。
4.  遇到消息，继续搜索 Producer / Consumer。
5.  遇到共享 DTO、API 或数据表，检查所有使用方。
6.  不得因为需求名称属于某个模块就停止跨仓调查。
