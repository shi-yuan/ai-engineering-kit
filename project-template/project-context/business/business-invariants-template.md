# Business Invariants

本文件记录跨需求长期有效、容易被误解且会影响实现正确性的业务不变量。

不要记录临时需求细节。

## 记录格式

  ID            业务域   不变量   原因 / 业务语义   代码证据   最后验证
  ------------- -------- -------- ----------------- ---------- ----------
  INV-XXX-001                                                  

## 编写原则

适合记录：

-   特殊值具有合法业务语义
-   关键状态不可逆或有固定流转约束
-   金额、余额、库存、额度之间的长期约束
-   批处理禁止使用某类分页方式
-   重复消息必须保持幂等
-   补偿任务与实时链路之间的关系

不适合记录：

-   单次需求的实现步骤
-   Coding Agent 行为规则
-   代码风格
-   临时上线方案
