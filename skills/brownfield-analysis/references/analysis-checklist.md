# Brownfield Analysis Checklist

完成 `00-change-analysis.md` 前逐项检查：

-   [ ] 已读取 `.agent-env.md` 并解析 `OPEN_SPEC_ROOT`
-   [ ] 已读取 system overview、architecture、module map、data model
-   [ ] 已读取相关业务流程和业务不变量
-   [ ] 已读取当前需求目录全部相关输入
-   [ ] 已通过代码证据识别真实入口
-   [ ] 已追踪主执行链路到最终副作用
-   [ ] 已搜索所有可能受影响的仓库
-   [ ] 相关跨进程调用已检查双方
-   [ ] 相关异步链路已检查生产端和消费端
-   [ ] 已检查持久化读写和数据语义
-   [ ] 已检查配置驱动行为
-   [ ] 已检查定时、重试、补偿、对账或修复行为
-   [ ] 已检查事务边界
-   [ ] 已检查锁、幂等和并发控制
-   [ ] 已检查边界值和特殊值
-   [ ] 已搜索已有测试中的业务语义
-   [ ] 已验证事实与假设明确分离
-   [ ] 待确认问题无法通过合理的继续代码搜索解决
-   [ ] 已区分确定受影响、可能受影响、已检查但不受影响
-   [ ] project-context 与代码的重大冲突已记录
-   [ ] 文档证据足够让另一个 Agent 开始 Design
