# Change Review Checklist

-   [ ] 已收集所有受影响仓库的完整 diff
-   [ ] 实际受影响仓库与 Design 范围已对比
-   [ ] 每个 Requirement Delta 可追溯到 Spec / Design / Task / Diff
-   [ ] 每个主要 Diff 都有需求或 Design 依据
-   [ ] 已检查无关重构和范围扩张
-   [ ] 已逐条检查业务不变量
-   [ ] 已检查特殊值和边界值语义
-   [ ] 已检查状态流转
-   [ ] 已检查金额、数量、余额或其他核心计算
-   [ ] 已检查分页、排序和批处理语义
-   [ ] 已检查幂等、重试和重复执行
-   [ ] 已检查补偿、对账和修复路径
-   [ ] 已检查 API / RPC 双方
-   [ ] 已检查消息生产端 / 消费端
-   [ ] 已检查数据写入方 / 读取方
-   [ ] 已检查配置和默认值
-   [ ] 已检查缓存行为
-   [ ] 已检查事务和并发
-   [ ] 已复核 Verification Report
-   [ ] BLOCKER / HIGH 问题均已明确
-   [ ] Review 结论符合规则
